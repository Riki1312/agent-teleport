# Managed isolated Codex imports

Implemented explicit `import --isolated` and `open --isolated` using private persistent native stores keyed by session identity and canonical target workspace. Versioned receipts expose ready imports through `list` and return stable local references for `resume`, `export`, and `save`; `status --isolated` compares repository saves with those copies. Native identities and existing histories remain unchanged. Runtime arguments are derived from the selected store, and one resolver routes native operations. Resume instructions are printed without preparing runtime resources; preparation occurs only when launching.

Known runtime configuration, profiles, instructions, skills, plugins, rules, hooks, and file-backed login are shared by reference. Database and log destinations are overridden for every managed native process, including list and doctor calls invoked inside a resumed session. Resume disables shared-daemon reuse. A native read-only startup probe rejects managed storage requirements that would override isolation before any isolated App Server can initialize shared databases. Keyring-backed login remains native and home-specific. Runtime links and private receipts are validated, and imports to the same store serialize through a local lock.

The native lifecycle test records synthetic sessions against a local scripted API, reproduces a conflicting ancestor, verifies a side-effect-free preview, imports and updates the same isolated copy, resumes through the public command, checks shared skills and file login, saves and exports continuation, and reimports it as an ordinary archive. It also proves interrupted appends recover through managed imports, and reference tests cover native forks without changing their identities. It verifies primary history and configuration bytes remain unchanged. Existing thread-open checks were made read-only because planning previously created lock directories during dry runs.

Validation: `make check` passed with required native E2E on Codex 0.169.0 and Claude Code 2.1.323. The full native E2E suite passed on the minimum-supported pair, Codex 0.165.0 and Claude Code 2.1.317. A private large-archive isolated dry run passed without creating managed storage. No release was published.
